# Security Policy

WebScopeX is intended for systems you own or are explicitly authorized to assess.

## Reporting a project vulnerability

For a public GitHub release, use GitHub's private vulnerability reporting feature when enabled. Avoid posting secrets, real credentials, private target data, or exploit details in public issues.

## Data handling

Reports and the SQLite history database are stored locally. Review report contents before sharing because enumeration evidence can contain internal hostnames, URLs, headers, or infrastructure metadata.
