# Reports

Every scan writes three local artifacts:

- `report.html` — responsive, searchable report for humans.
- `report.json` — complete evidence and summary for automation.
- `graph.json` — Recon Graph nodes and edges.

The HTML report includes summary cards, target/scope metadata, Recon Graph inventory, module/severity filters, and evidence details. Treat reports as potentially sensitive because they may contain infrastructure metadata.
